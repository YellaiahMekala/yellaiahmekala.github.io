## How to read the status labels

- **Built** means confirmed by tests or a recorded run.
- **In progress** means partly built.
- **Planned** means designed only.
- **TODO** marks a fact the author still has to confirm. Nothing is filled in by guesswork.

Code for private projects is not published. A code walkthrough is available on request.
