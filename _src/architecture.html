Design principles

Model Proposes, Humans Decide

The model returns a cited proposal. Authorized reviewers approve, and the maker and checker must be different people.

Retrieval Before Generation

Answers are built from retrieved, cited evidence, and the assistant declines when the evidence is weak.

Evaluation Over Intuition

Fixed question sets and a written decision rule. A multi-agent mode that missed its rule stayed switched off.

Least-Privilege Tool Access

Agent tools are read-only, role-checked and audited. The tenant comes only from the signed token, never from a header.

Auditability By Design

A hash-chained audit trail, one ledger row per model call and an audit row per tool call.

Deterministic Business Logic

Approval levels, budgets and idempotency are ordinary tested code, not prompts. The model never sets them.
